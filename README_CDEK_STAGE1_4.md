# STUDIO 82 — CDEK stage 1.4

Исправление клиентского отображения СДЭК.

Что изменено:

- Покупатель больше не видит технический текст про расчёт СДЭК, адрес отправки и API.
- Покупатель больше не видит габариты, вес и тип коробки в checkout, на экране успешного заказа и в “Мои заказы”.
- В клиентском интерфейсе остаётся только понятная информация: способ доставки, город/ПВЗ или адрес, стоимость доставки и срок.
- Цена доставки принудительно равна сумме, которую возвращает СДЭК API, без ручной наценки, даже если в Vercel случайно осталась переменная CDEK_DELIVERY_MARKUP_PER_PAIR.
- Технические данные упаковки продолжают сохраняться в заказе для будущего создания отправления СДЭК.
- В админке упаковка СДЭК по-прежнему отображается, чтобы владелец видел, с какими параметрами считалась доставка.

После установки:

1. Commit to main
2. Push origin
3. Vercel → дождаться Ready
4. Полностью закрыть Mini App в Telegram и открыть заново

Переменную CDEK_DELIVERY_MARKUP_PER_PAIR можно удалить или оставить 0.
