# STUDIO 82 — Production Polish Stage 3 Light

Этот пакет дорабатывает stage 2 без разделения обуви на мужскую/женскую/унисекс.

## Что изменено

1. После успешной оплаты ЮKassa заказ автоматически получает статус `На сборке`.
2. Блок `Доставка СДЭК` в `Мои заказы` показывается всегда для СДЭК-заказов, даже если отправление ещё не создано.
3. Если трека ещё нет, клиент видит понятный текст: трек появится после создания и обработки отправления.
4. Кнопка ручного обновления СДЭК показывается только когда отправление уже создано.
5. Добавлена автоматическая синхронизация статусов СДЭК через `/api/cron/cdek-status-sync` раз в час.
6. Создание отправления СДЭК из админки теперь доступно только после оплаты заказа.
7. Курьерская доставка СДЭК разбита на поля: улица, дом/корпус, квартира/офис, комментарий.
8. Для ПВЗ/постамата по-прежнему передаётся только `delivery_point`, для курьера — только `to_location.address`.
9. В каталоге добавлена пагинация: 10 / 20 / 50 / 100 товаров на странице.
10. Добавлен `.npmrc` с официальным npm registry, чтобы Vercel не падал из-за неправильного реестра.

## SQL

Для новых полей курьерского адреса желательно один раз выполнить:

`sql/02_stage3_light_cdek_autostatus.sql`

Если SQL не выполнить, код попробует сохранить курьерский адрес в старое поле `cdek_recipient_address`, но лучше выполнить SQL сразу.

## Vercel

Новая переменная необязательная:

`CRON_SECRET`

Если оставить пустой — cron endpoint будет доступен без секрета. Если указать значение, endpoint потребует заголовок:

`Authorization: Bearer <CRON_SECRET>`

Для Vercel Cron переменную можно не добавлять на первом этапе.

## Как обновить

1. Распаковать архив.
2. Скопировать файлы в проект с заменой.
3. Выполнить SQL `sql/02_stage3_light_cdek_autostatus.sql` в Supabase.
4. GitHub Desktop → Summary: `Production polish stage 3 light`.
5. Commit to main.
6. Push origin.
7. Дождаться Vercel Ready.
8. Полностью закрыть Mini App в Telegram и открыть заново.

## Проверка после деплоя

1. Создать тестовый заказ СДЭК ПВЗ.
2. Оплатить тестовый заказ или проверить оплату.
3. Убедиться, что статус стал `На сборке`.
4. В `Мои заказы` должен быть блок `Доставка СДЭК` даже без трека.
5. В админке кнопка `Создать отправление СДЭК` должна быть активна только после оплаты.
6. Создать отправление СДЭК.
7. Проверить, что UUID/трек/статус отображаются в админке и у клиента.
8. Проверить `/api/cron/cdek-status-sync` после деплоя.
