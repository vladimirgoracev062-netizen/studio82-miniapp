# STUDIO 82 — CDEK stage 1.3

Обновление логики расчёта доставки СДЭК.

## Что изменено

- Убрана ручная наценка `+100 ₽ за пару`.
- Клиенту показывается цена, которую вернул СДЭК API.
- Расчёт теперь использует реальные короба СДЭК для обуви:
  - 1 пара → короб L, 31 × 25 × 38 см, вес 1500 г
  - 2–4 пары → короб XL, 60 × 35 × 30 см, вес 1500 г × количество пар
  - 5+ пар → несколько коробов: XL на 2–4 пары + L для остатка 1 пары
- В запрос калькулятора СДЭК теперь отправляется массив `packages`, если коробов несколько.
- В checkout, админке и «Мои заказы» отображается тип короба СДЭК.
- Адрес отправки остаётся: Москва, улица Пришвина 26.

## Что важно

Чтобы цена у клиента максимально совпадала со списанием в СДЭК, дальше нужно создавать отправление через API с теми же параметрами: тариф, город, ПВЗ/адрес, вес и короба.

Если заказ создавать вручную в кабинете/приложении СДЭК, цена может отличаться из-за другого тарифа, упаковки, дополнительных услуг или перемера.

## Vercel переменные

Рекомендуемые значения:

```env
CDEK_BASE_URL=https://api.cdek.ru
CDEK_FROM_CITY_CODE=44
CDEK_SENDER_ADDRESS=Москва, улица Пришвина 26
CDEK_PACKAGE_WEIGHT_GRAMS=1500
CDEK_DELIVERY_MARKUP_PER_PAIR=0
```

Переменные `CDEK_PACKAGE_LENGTH_CM`, `CDEK_PACKAGE_WIDTH_CM`, `CDEK_PACKAGE_HEIGHT_CM` можно оставить, но новая логика коробов использует фиксированные размеры СДЭК L/XL.
