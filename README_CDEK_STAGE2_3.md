# STUDIO 82 — CDEK stage 2.3

Исправление создания отправления СДЭК для заказов до ПВЗ/постамата.

## Что исправлено

- Для доставки `ПВЗ / постамат` теперь в СДЭК отправляется только `delivery_point` получателя.
- `to_location` больше не передаётся вместе с `delivery_point`, чтобы СДЭК не считал это двумя адресами получателя.
- Исправлена ошибка:
  - `v2_delivery_address_multivalued: Recipient address and recipient delivery point can't be filled both`
  - `v2_field_is_empty: [to_location.address] is empty`
- Ошибки `СДЭК API ...` в админке подсвечиваются как ошибка, а не как зелёное сообщение.

## Проверка

1. Загрузить код.
2. Дождаться Vercel Ready.
3. Открыть Mini App заново.
4. В админке нажать `Создать отправление СДЭК` для заказа с ПВЗ.

Если появится новая ошибка — она уже будет следующей конкретной проверкой СДЭК.
