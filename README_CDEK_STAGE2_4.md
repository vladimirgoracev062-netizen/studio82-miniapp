# STUDIO 82 — CDEK stage 2.4

Обновление СДЭК: учёт объявленной стоимости/страхования и корректный промежуточный статус.

## Что изменено

- В расчёт доставки СДЭК теперь передаётся услуга `INSURANCE` с объявленной стоимостью заказа.
- Цена доставки для клиента берётся как итоговая сумма от СДЭК: тариф + сбор за объявленную стоимость.
- Ручная наценка по-прежнему не используется.
- При создании отправления в СДЭК также передаётся `INSURANCE`, чтобы расчёт и фактическое создание были ближе друг к другу.
- После создания отправления статус заказа теперь `Отправление создано`, а не `Передан в СДЭК`.
- Формулировка для СДЭК: `Отправление создано, ожидает передачи в СДЭК`.

## Переменные Vercel

Можно добавить, если нужно явно управлять процентом:

```env
CDEK_DECLARED_VALUE_RATE=0.0075
```

По умолчанию уже используется `0.0075`.

## Как проверить

1. Обновить проект и дождаться Vercel Ready.
2. Создать заказ с СДЭК.
3. Проверить, что доставка стала выше на сумму сбора за объявленную стоимость.
4. В админке нажать “Создать отправление СДЭК”.
5. Проверить, что статус стал “Отправление создано”, а не “Передан в СДЭК”.
