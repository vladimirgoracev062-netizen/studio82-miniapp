# CDEK stage 2.5 — НДС, объявленная стоимость и нормальные товары в СДЭК

Что исправлено:

- В расчёте доставки учитывается НДС СДЭК по услугам и сбору за объявленную стоимость.
- Для клиента цена доставки остаётся одной строкой: «Доставка СДЭК».
- Ручной наценки магазина нет.
- В создании отправления больше не используется артикул `studio82-shoes-1`.
- В СДЭК в товары передаётся конкретное название: бренд/модель/цвет/размер.
- Для нескольких товаров позиции распределяются по коробам.

Переменные Vercel:

```env
CDEK_INCLUDE_VAT=true
CDEK_VAT_RATE=0.22
CDEK_DELIVERY_MARKUP_PER_PAIR=0
```

Если в будущем СДЭК начнёт отдавать стоимость уже с НДС, можно поставить:

```env
CDEK_INCLUDE_VAT=false
```
