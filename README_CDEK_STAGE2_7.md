# CDEK stage 2.7 — быстрый поиск городов

Что изменено:

- Поиск городов больше не ждёт загрузки полного справочника всех городов РФ перед выдачей результата.
- Сначала выполняется быстрый запрос в СДЭК по введённому тексту и частым вариантам написания.
- Для Ростов / Ростов на Дону / Ростов-на-Дону сохраняется расширенная логика алиасов.
- Добавлен серверный кэш результатов поиска на 30 минут.
- Добавлен клиентский sessionStorage-кэш, чтобы повторный ввод того же города открывался быстрее.
- Debounce автопоиска снижен до 300 мс.

После установки нужно сделать обычный деплой. SQL и переменные Vercel менять не нужно.
