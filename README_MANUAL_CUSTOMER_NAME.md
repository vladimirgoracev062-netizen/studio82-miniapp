# STUDIO 82 — ручной ввод ФИО в checkout

Исправление checkout:

- поле «ФИО» больше не заполняется автоматически из Telegram;
- из Telegram подтягивается только номер телефона;
- имя покупателя в заказе сохраняется именно то, которое клиент сам ввёл в поле «ФИО»;
- Telegram ID и username по-прежнему используются для привязки заказов к аккаунту и разделения заказов клиентов.

После обновления нужно полностью закрыть Mini App в Telegram и открыть заново.
