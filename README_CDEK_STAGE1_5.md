# STUDIO 82 — CDEK stage 1.5

Исправления:

- Улучшен поиск городов СДЭК.
- Поиск теперь не зависит от дефисов: `Ростов`, `Ростов на Дону`, `Ростов-на-Дону` должны находить Ростов-на-Дону.
- Добавлен серверный кэш списка городов РФ из СДЭК, затем поиск идёт локально по нормализованным названиям.
- Добавлены частые алиасы: СПБ/Питер/Санкт-Петербург, Нижний/Нижний Новгород и т.д.
- В оформлении заказа, созданном заказе, админском уведомлении и сохранённых order_items теперь название товара включает бренд.

Пример:

```
NEW BALANCE 471 белый/голубой, размер 38 × 1
NIKE Field General голубой, размер 37.5 × 1
```

Цена доставки по-прежнему берётся напрямую из СДЭК API, без ручной наценки.
Технические данные упаковки скрыты от клиента и сохраняются для админки/будущего создания отправлений.
