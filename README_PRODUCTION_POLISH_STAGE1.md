## Как обновить

1. Скопировать содержимое архива в корень проекта с заменой.
2. Commit в GitHub Desktop:
   `Add reservation and legal pages`
3. Push origin.
4. Дождаться Vercel Ready.
5. В Supabase выполнить SQL:
   `sql/01_cdek_stage1_orders.sql`

## Новая переменная Vercel

Опционально можно добавить:

```env
ORDER_RESERVATION_MINUTES=10
```

Если не добавлять, по умолчанию используется 10 минут.

## Важная логика

Товар списывается из остатка при создании заказа и держится в брони 10 минут.
Если заказ не оплачен за 10 минут, остаток возвращается в наличие.
Если ЮKassa вернула `payment.canceled`, остаток возвращается сразу.
Если оплата успешная, Telegram-уведомление отправляется администратору только один раз.
