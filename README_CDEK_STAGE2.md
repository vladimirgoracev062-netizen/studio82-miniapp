# STUDIO 82 — CDEK stage 2

Добавлено ручное создание отправления СДЭК из админки и обновление статуса доставки.

## Что появилось

- В админке у заказа СДЭК есть кнопка `Создать отправление СДЭК`.
- После создания сохраняется `cdek_order_uuid`.
- Если СДЭК уже выдал номер отправления, он сохраняется как трек-номер.
- В админке есть кнопка `Обновить статус СДЭК`.
- В разделе клиента `Мои заказы` статус СДЭК обновляется при открытии страницы, если отправление уже создано.
- Отправление создаётся с теми же данными, что использовались для расчёта: тариф, город, ПВЗ/адрес, упаковка, габариты и вес.

## Важно

Для создания отправления нужно добавить в Vercel переменную:

```env
CDEK_SENDER_PHONE=79999999999
```

Также должны быть:

```env
CDEK_BASE_URL=https://api.cdek.ru
CDEK_CLIENT_ID=...
CDEK_CLIENT_SECRET=...
CDEK_FROM_CITY_CODE=44
CDEK_SENDER_NAME=STUDIO 82
CDEK_SENDER_ADDRESS=Москва, улица Пришвина 26
CDEK_PACKAGE_WEIGHT_GRAMS=1500
CDEK_DELIVERY_MARKUP_PER_PAIR=0
```

## Исправление stage 2.1

Для создания отправления СДЭК теперь используется `shipment_point` — код ПВЗ, куда STUDIO 82 сдаёт посылки.
Для адреса Москва, ул. Пришвина, 26 используется код ПВЗ:

```env
CDEK_SHIPMENT_POINT_CODE=MSK1305
```

Важно: для тарифов 136/137 одного адреса отправки недостаточно. СДЭК должен знать конкретный пункт приёма отправления.
