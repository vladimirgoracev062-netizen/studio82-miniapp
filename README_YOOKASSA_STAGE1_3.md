# YooKassa stage 1.3 — описание платежа и Москва

Что изменено:

- Описание платежа в ЮKassa теперь формируется из состава заказа:
  - бренд / модель / цвет;
  - размер;
  - количество.
- Для длинных заказов описание безопасно сокращается до лимита ЮKassa 128 символов.
- Доставка по Москве в checkout теперь описана как бесплатная.
- Сообщение менеджеру по Москве теперь открывается только после оплаты и говорит, что заказ уже оплачен.

Пример описания платежа:

`STUDIO 82 №24: NB 471 белый/голубой р37 ×1`

Если в заказе много позиций и они не помещаются в лимит описания ЮKassa, в описании будут первые позиции и пометка `+N поз.`. Полный состав заказа сохраняется в приложении, админке и в карточке заказа.
