# STUDIO 82 Telegram Mini App

MVP-версия магазина STUDIO 82.

## Что есть

- каталог товаров;
- карточка товара;
- активные и серые размеры по остаткам;
- корзина;
- оформление заказа;
- личный кабинет клиента;
- админка для одного владельца;
- добавление товаров;
- загрузка фото в админке;
- редактирование цены, описания, размеров и остатков.

## Админка

Админка находится по адресу:

`/admin`

Ссылка на админку скрыта из нижнего меню магазина. Пароль задаётся переменной окружения:

`NEXT_PUBLIC_ADMIN_PASSWORD`

Для MVP по умолчанию используется пароль `admin82`.

## Важно

Текущая версия сохраняет товары и заказы в localStorage браузера. Это подходит для теста интерфейса, но не для боевого магазина. Следующий этап — подключение базы данных и storage для фото, чтобы изменения в админке видели все клиенты.
