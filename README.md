# STUDIO 82 Telegram Mini App

Обновленная MVP-версия магазина STUDIO 82.

## Что добавлено

- Админка скрыта из нижнего меню и доступна только по `/admin`.
- Вход в админку по паролю.
- Полноценное добавление товара.
- Загрузка нескольких фото с компьютера.
- Добавление фото ссылками, по одной ссылке на строку.
- Квадратные фото-контейнеры 1:1.
- Загруженные фото автоматически вписываются в квадрат без обрезки.
- Редактирование бренда, названия, цвета, цены, описания.
- Управление размерами и остатками.
- Серые неактивные размеры для клиента, если остаток 0.
- Скрытие и публикация товара.
- Удаление товара.
- Поиск и фильтр по бренду в каталоге.
- Корзина с изменением количества.
- Заказы и статусы заказов.

## Пароль админки для теста

`admin82`

## Важно

Пока это MVP: товары, фото и заказы сохраняются в localStorage браузера. Для боевой версии нужно подключить Supabase/PostgreSQL и хранилище фото, чтобы изменения из админки видели все клиенты.
