# STUDIO 82 Telegram Mini App

Готовая первая версия витрины STUDIO 82 для Vercel.

## Что есть
- каталог товаров из таблицы;
- дизайн в стиле STUDIO 82;
- карточка товара;
- размеры и остатки;
- локальная админ-панель `/admin`;
- редактирование названия, описания, цены, фото, размеров и остатков;
- добавление новых товаров;
- корзина-заявка без оплаты;
- подготовка под Telegram Mini App.

## Как запустить на Vercel
1. Загрузите содержимое этой папки в GitHub репозиторий `studio82-miniapp`.
2. В Vercel нажмите Import.
3. Framework Preset должен стать `Vite`.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Нажмите Deploy.

## Важно
Админка в этой версии хранит изменения в браузере через localStorage. Для реального магазина с общей админкой, заказами, ЮKassa и остатками нужна серверная база данных.
